## 1. Deskripsi Singkat Mengenai Repository

Repository (atau sering disingkat repo) adalah tempat penyimpanan digital terpusat di mana seluruh file proyek, kode sumber (source code), aset, dokumentasi, beserta seluruh riwayat revisi (history) dari file-file tersebut disimpan dan dikelola.

Repositori biasanya di-host secara online menggunakan platform manajemen version control seperti GitHub, GitLab, atau Bitbucket, ataupun disimpan secara lokal di komputer pengembang. Setiap kali ada perubahan, penambahan, atau penghapusan kode, sistem pengelola (seperti Git) akan mencatat siapa yang mengubah, kapan diubah, dan apa perubahannya.

## 2. Tujuan atau Kegunaan Repository

Repositori memiliki peran yang sangat vital dalam pengembangan perangkat lunak modern. Berikut adalah beberapa kegunaan utamanya:

- Manajemen Versi (Version Control): Melacak setiap perubahan kode dari waktu ke waktu. Jika terjadi error atau bug setelah pembaruan, pengembang dapat dengan mudah melihat riwayat revisi dan mengembalikan kode ke kondisi stabil sebelumnya (rollback).

- Kolaborasi Tim: Memungkinkan banyak pengembang untuk bekerja secara bersamaan pada proyek yang sama tanpa saling menimpa pekerjaan (overwrite). Fitur seperti branching (cabang) dan pull request memungkinkan tim meninjau kode sebelum digabungkan ke proyek utama.

- Penyimpanan Aman dan Cadangan (Backup): Menjaga agar kode proyek tetap aman dari kerusakan perangkat keras, kehilangan data, atau kegagalan sistem karena tersimpan di server cloud yang andal.

- Portabilitas dan Aksesibilitas: Memungkinkan pengembang untuk mengakses, mengunduh (clone), atau melanjutkan pekerjaan proyek dari perangkat mana pun di berbagai lokasi dengan mudah.

- Integrasi & Deployment Otomatis (CI/CD): Banyak repositori masa kini terintegrasi langsung dengan layanan otomatisasi untuk melakukan pengujian (testing) dan peluncuran aplikasi (deployment) secara otomatis setiap kali ada kode baru yang diunggah.
